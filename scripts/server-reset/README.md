# MXZG 内网游戏清档工具

清档会重置指定实例上所有游戏账号的角色、会话和玩法进度。用于共享验收服时，选择时间段并提前告知正在联调的同事。游戏包、证书、个人服登记和构建台账号、审批、任务历史存放在游戏数据库之外。

## 在打包机清共享服

打开桌面的共享服清档快捷方式，先核对窗口中显示的区服、游戏地址和数据库路径。输入完整的 `local-1` 后按回车确认；留空并按回车即可取消。共享服原先在线时，工具会停服，准备并校验新库，替换数据库并留下原库备份，随后启动共享服并检查 HTTPS 和 WebSocket。共享服原先已停止时，完成后会继续保持停止。已经退役的「开发二服」在清档后继续下线。开发机上的 Hao 个人服有独立的数据库。

完成后重新打开共享 H5，选「共享验收服」并登录。可以用原来的开发测试账号进入，此时会获得新角色。

## 在开发机清个人服

1. 将包含本工具的 `main` 更新合入开发机使用的分支。工具在仓库的 `scripts/server-reset/`。先用 `backend/dev.ps1 personal` 成功启动过目标个人服，确保本机已有该服的数据库和 `server.p12`。首次配置时，从仓库根目录在 PowerShell 执行：

   ```powershell
   Set-Location .\scripts\server-reset
   if (-not (Test-Path -LiteralPath .\reset.json)) {
       Copy-Item -LiteralPath .\personal.example.json -Destination .\reset.json
   }
   notepad .\reset.json
   ```

   `reset.json` 是本机配置，Git 会忽略它。使用独立 ZIP 时，解压后在工具目录从复制示例这一步开始。
2. 用文本编辑器把 `checkout` 改为这台开发机上的 **MXZG 仓库根目录**，在该目录下应能找到 `backend/dev.ps1`。Windows 路径可以用正斜杠。示例已填好 Hao 的区服信息，另一位同事应替换为自己的区服 ID、显示名、开发机 IP、端口和实际使用的共享 H5 来源。证书口令留在开发机，由启动窗口交互输入。
3. 在工具目录的 PowerShell 执行下面的预览，核对区服 ID 和数据库路径。Hao 的目标文件应为开发机项目内的 `backend/.local/lan-personal/dev-hao/game.mv.db`。

   ```powershell
   .\Reset-GameServer.ps1 -Config .\reset.json -Preview
   ```

4. 双击工具目录的 `Reset.cmd`，核对目标后输入完整的区服 ID，例如 `dev-hao`。若个人服正在运行，在**原来的个人服终端**按 `Ctrl+C`。清档窗口会等待端口和数据库文件释放，最多两分钟。每台开发机可为自己的 `Reset.cmd` 创建桌面快捷方式。
5. 清档成功后，当前窗口会调用开发机原有的 `backend/dev.ps1 personal` 编译并启动个人服。按提示输入本机证书口令，保持该窗口运行。打开共享 H5，选择自己的个人服，登录后核对角色重新开始。使用原有 ID 和地址时，选服目录中的个人服条目继续有效。

工具使用 JDK 21 和与该 H2 数据库匹配的 JDBC 驱动。个人环境自动查找失败时，可在自己的 `reset.json` 增加 `javaPath` 和 `h2Jar`，填写本机 JDK 21 的 `bin/java.exe` 和项目对应版本的 `h2-版本.jar` 两个文件的绝对路径，重新执行预览。

## 备份和恢复

每次清档使用目标数据库旁的 `reset-backups` 目录保留离线备份。备份内包含清档前的测试角色和会话，请只放在目标机器或获准使用的备份位置。

若原先在线的共享服在换库后启动或健康检查失败，工具会尝试恢复原库、重启并再次检查服务。回滚成功时，原库已经回到原路径，本次未通过验证的新库以 `.failed.mv.db` 留在备份目录。若恢复也报错，先核对窗口指出的错误、当前运行状态、原文件和备份目录。个人服调用本地开发脚本后，如果遇到编译、端口或证书口令错误，可先修正并用原来的命令再次启动。清档前的原库仍可从备份取回。

手工恢复时，先完全停止对应游戏实例，将当前数据库另存。再把同一实例的指定备份复制回窗口显示的原文件路径，随后使用原启动入口启动并核对区服和角色。恢复会覆盖清档后产生的进度。请选取普通 `.mv.db` 备份，其文件名前缀包含目标区服 ID 和清档时间。

## 向其他同事分发

分发 ZIP 时只打包通用脚本、配套程序、本说明与 `personal.example.json`；同事在开发机另存 `reset.json`。管理员可把分发包的 SHA-256 随交接消息发给同事，开发机复制到本地后按下面的方式核对，再解压配置。

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath 'D:\Downloads\MXZG-个人服清档工具.zip'
```
