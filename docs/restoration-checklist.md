# 六个核心流程的还原验收清单

更新：2026-11-04。当前状态以[进度首页](development-progress.md)为准，接入门槛见[实施路线](restructuring-plan.md)。本次为代码与文档核查，没有重新游玩正式服或执行页面验收。

| 流程 | 当前可用范围 | 下一次对照重点 |
|---|---|---|
| 登录 | WS＋Protobuf 开发登录、选服、恢复 | 正式身份、创角与初始化；断网/顶号/换号；小游戏真机 |
| 主城/角色 | 头像入口、只读详情、经验条及已接入导航 | 同等级经验比例、头像/文字/层级、详情开关；完整主城入口仍未恢复 |
| 英雄 | 列表、只读详情、基础技能、普通四槽、部分服务端属性 | 进化与共享战斗输入；星级图形/富文本差异；升级和穿脱仍关闭 |
| 背包 | 统一状态、分类/详情、期限逐件格子和倒计时 | 同配置排序/数量/期限；后台恢复；使用、分解及权益效果仍关闭 |
| 战斗 | 当前入口暂停，保留基础普攻与历史表现代码 | 先复核阵容/技能/属性/战报；再验真实挑战、结算、返回及重试；不沿用历史通过作为当前已接通 |
| 挂机 | 当前入口暂停，保留普通计时和领取规则代码 | 关卡对应收益、离线/上限/随机保底、重复领取和重启恢复；完整加成另列 |

正式服参考使用已授权 hao1；账号、等级、资产、开放条件和视口差异先记录，不能直接认定为 UI 错误。源码/配置与正式服冲突时记录证据并确认，不自行改规则。

## 每项修复的完成标准

每个差异记录原版路径/协议/配置行或截图、当前入口、预期行为、修复提交和复验结果。代码/配置与正式服冲突时保留两份证据并询问负责人，不凭经验改数值。

“完成”必须覆盖入口和退出、成功与失败条件、数据持久化与重复操作、规定尺寸的真实表现。资产功能需验证后端权威与断线恢复；预制体需检查脚本/UUID/动态资源与页面对应关系。列表遵守 SuperScroll，模块遵守背包职责划分，不为统一名字而重置 UUID。
