## 坐标与命名

BagView 样板根尺寸 640×960、锚点 (0,0)、位置 (-320,-480)。页面根位置按 (anchor-0.5)×size 居中；中心锚点页面自然为 (0,0)。子节点使用各自坐标，顶部/底部锚点、进度条、Cell、红点和特效节点不机械转换。逻辑设计尺寸 640×1280，部分主城/背景为 720×1280；可见视口与安全区由既有适配处理，不混淆坐标层。

页面资源与实际 View 同名；Cell、子视图按绑定组件命名，Common 组件用 Shell 类名；纯组合资源不新增空类。22 组映射及 UUID 见 [改名清单](../config/prefab-renames.json)。改名后重新生成资源目录，同步计划、动态路径、嵌套资源、动画和检查工具。

## 继续有效的美术与安全区约定

羊皮纸窗口不因 720 宽背景而放大至 1.069；宽度足够时比例为 1，窄屏只缩小，背景独立铺满。背包列表使用静态 view/Mask/content 关系，禁止重新采用运行时重挂 content 或移除 Mask 的旧方案。九宫格与保留界面的原美术偏差记录于 asset-provenance.json，未因本轮原点修复宣称 1:1。安全区由 framework/ui/safeAreaLayout 读取，safeDebug=1 仅用于调试显示；不要用旧 Boot 日志作为当前入口证据。
